## Project: Resilient urgent orchestration for SAGE

This project applies an application-agnostic, explainable scheduler to the
Mortimus field-vision use case. The scheduling core can also be connected to
other SAGE/Waggle applications—or another orchestrator—through a small adapter.
Mortimus is the application shown here, not a scheduler dependency.
